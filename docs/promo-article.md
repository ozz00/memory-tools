# 把 Anki 装进微信里：一个为六西格玛备考做的记忆卡工具

备考六西格玛黑带的人，大多都有一副自己整理的 Anki 牌组。麻烦在使用：Anki 主要在电脑上，通勤排队的碎片时间够不着；手机上装一份又要同步、又要配置，折腾完二十分钟也过去了。更现实的是——每天该复习多少、能不能赶在考前过完一轮，全凭感觉。

这是个跑在微信里的小程序，不用下载，点开就用。你把自己的牌组（Anki 导出的 TXT）导入进去，剩下交给它：

**自动排期。** 基于 SM-2 间隔重复算法，按每张卡的掌握程度安排下次复习。答得顺的往后推，卡住的明天再来，不用自己记哪张该复习了。

**倒推每日任务。** 填一个考试日期，它按牌组规模和剩余天数算出每天该推进多少，并预留考前巩固时间。不用再纠结「今天该学几张」。

**选择题也能练。** 不只有正反面闪卡，四选一可点选作答、即时判对错，更贴近真实考试的手感。

**大牌组装得下。** 存储做了分片处理，两千张以上也能稳定落盘；答一张卡只写一小块数据，不卡顿、不丢进度。

你的卡片和复习记录都存本机，不上传、不公开。它本身不提供任何学习内容——你导入什么，它就帮你记住什么。

如果你已经在用 Anki 备考，只是苦于「想复习的时候不方便」，可以把它当作通勤路上的那一块屏幕。
